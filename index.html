الوحدة الثالثة: هياكل البيانات الخطية

الدرس الأول: القواميس (Dictionaries in Python)

ما هو القاموس (Dictionary)؟

القاموس هو هيكل بيانات قابل للتغيير يتضمن مجموعة من العناصر، ويتكون كل عنصر من زوج من القيم على صورة (key: value) أي (المفتاح : القيمة). يتم الوصول إلى عناصر القاموس من خلال مفاتيحه وليس بواسطة رقم الفهرس.

1. طرق إنشاء القاموس

الطريقة الأولى (باستخدام الأقواس المتعرجة `{}`):

ArabGulf = {"Saudi Arabia": "Riyadh", "Oman": "Muscat", "Bahrain": "Manama"}
print(ArabGulf)

الطريقة الثانية (باستخدام أمر الإنشاء `dict()`):

ArabGulf = dict(SaudiArabia="Riyadh", Oman="Muscat", Bahrain="Manama")
print(ArabGulf)

2. الوصول إلى عناصر القاموس وطباعتها

يمكن الوصول إلى عناصر القاموس عبر طريقتين أساسيتين:

ArabGulf = {
    "SaudiArabia": "Riyadh",
    "Oman": "Muscat"
}

# الطريقة الأولى: باستخدام مفتاح العنصر داخل أقواس مربعة
capital1 = ArabGulf["SaudiArabia"]
print(capital1) # النتيجة: Riyadh

# الطريقة الثانية: باستخدام دالة get
capital2 = ArabGulf.get("Oman")
print(capital2) # النتيجة: Muscat

3. التعديل على عناصر القاموس

يمكن تحديث وتغيير قيمة عنصر داخل القاموس من خلال تحديد المفتاح وإسناد القيمة الجديدة:

Employees = {
    "Khalid": "Project Manager",
    "Saad": "Data Analyst"
}
Employees["Saad"] = "Data Scientist"
print(Employees)

4. طرق حذف عناصر القاموس

يتيح بايثون عدة خيارات لحذف العناصر أو القاموس بالكامل:

أ) استخدام كلمة `del` لحذف عنصر محدد أو القاموس بأكمله:

ArabGulf = {
    "SaudiArabia": "Riyadh",
    "Oman": "Muscat",
    "Bahrain": "Manama"
}

# حذف عنصر معين بالمفتاح
del ArabGulf["Oman"]
print(ArabGulf)

# حذف القاموس بأكمله
del ArabGulf

ب) استخدام دالة `clear()` لحذف جميع عناصر القاموس مع إبقاء القاموس فارغاً:

ArabGulf = {
    "SaudiArabia": "Riyadh",
    "Oman": "Muscat"
}
ArabGulf.clear()
print(ArabGulf) # النتيجة: {}

أنشطة وتدريبات عملية

تدريب (1): إنشاء وطباعة قاموس شخصي

المطلوب: أنشئ قاموساً خاصاً باسمك، واسم العائلة، ثم اطبعه.

# الحل البرمجي المقترح:
my_info = {
    "first_name": "محمد",
    "last_name": "العتيبي"
}

print(my_info)

تدريب (2): تعبئة قاموس من المستخدم

المطلوب: أنشئ قاموساً يتم تعبئته من قبل المستخدم، بحيث يدخل رقم هاتفه واسمه ثم يطبعهما.

# الحل البرمجي المقترح:
user_name = input("أدخل اسمك: ")
user_phone = input("أدخل رقم هاتفك: ")

user_profile = {
    "name": user_name,
    "phone": user_phone
}

print(user_profile)
